# 浏览器手工验收

自动测试使用模拟 DOM/渲染接口，不能替代真实 Tripo、用户脚本管理器及 WebCodecs 验收。

## 3.12.11 安装与入口验收

- 从 GitHub Raw 的 `v3.12.11` 固定版本链接安装或更新，停用重复安装的旧副本并刷新 `https://studio.tripo3d.ai/zh/workspace/generate`。
- 面板或用户脚本管理器显示 v3.12.11；仅修改本地仓库不会更新浏览器里运行的 v3.12.10。
- 用户脚本元数据不含 `@require`；顶部 DCC Bridge 旁出现“旋转助手”按钮，初始面板隐藏。
- “旋转助手”入口沿用 DCC Bridge 的高度、内边距和圆角，最小宽度 100px，图标和文字居中且没有挤压相邻按钮。
- 点击按钮打开/关闭面板；点击面板内“隐藏面板”后仍可用顶部按钮打开。
- 切换工作区子页面或让顶部栏重绘后，按钮仍存在且只出现一次。
- 状态请求失败时按钮不出现；恢复网络后刷新，按钮重新出现。

以下是旧版本的专项验收记录，发布新版本时仍应检查相关功能。
使用 Chrome 最新版、Tampermonkey/Violentmonkey，先发布并推送 `v3.9.6` 标签，再安装根目录入口脚本检查：

- [ ] 油猴详情页显示入口通过 GitHub Raw 加载 `v3.9.6/dist/tripo-core.min.js`。
- [ ] 已加载模型，面板显示版本 3.9.6；“检查逐帧入口”成功。
- [ ] 将仓库临时改为私有，刷新 Tripo 页面；面板不再出现。恢复公开后刷新，面板恢复。
- [ ] 关闭录制，启动旋转，在运动中按 Esc；再次旋转/截图能正常开始。
- [ ] 关闭录制，旋转时切后台，回前台能重新操作。
- [ ] 一键导出仅截图，在材质切换/截图等待期间按 Esc；不开始后续项目，材质、线框、视角恢复。
- [ ] 一键导出视频，在倒计时和编码期间分别停止；没有不完整视频，新任务能正常开始。
- [ ] 隐藏坐标轴时放大/平移模型到右上角，普通 PNG、透明 PNG/MOV 没有矩形缺口；结束后页面坐标轴恢复。
- [ ] 开启“保留坐标轴”时，标签页截图保留该 DOM 叠层。模型 Canvas 不会额外合成 DOM 坐标轴。
- [ ] 整标签页截图：保存框 → 开始共享 → 当前标签页；画面是当前材质、无助手面板，停止后共享指示消失。
- [ ] 取消共享、共享播放失败、等待共享帧期间停止，均能再次截图。
- [ ] 默认 MP4 195 帧 / 60fps（3 秒旋转 + 0.25 秒停止），播放器正常播放。
- [ ] 透明 MOV 在支持 PNG-in-MOV 的软件中有 Alpha；批量跨材质保持视角一致。
- [ ] 模拟目录写入失败后，保存恢复窗口仍保留文件；“停止”不丢弃未保存 Blob，可重试/另存为/明确放弃。

如果平台把坐标轴直接绘入 WebGL，同一 Canvas 中的模型与坐标轴无法通过矩形遮罩安全分离。
当前实现只隐藏可识别的独立 DOM 叠层；遇到未知结构保留画面，不擦除模型像素。

## 3.9.7 账号登录与会话刷新

- 在工作区首页、带语言前缀首页和 Generate 子页面安装本地单文件包，确认面板可见，原有录制和快捷键仍正常。
- 用测试账户在“账号登录 / 刷新会话”提交密码，确认输入框立即清空、请求期间按钮禁用，原生页面同步登录成功状态。
- 查看 Network：登录 flow → 带 CSRF 的 password POST → 原生登录状态同步；不要保存含密码 / Cookie / JWT 的 HAR 到仓库。
- 正确/错误密码、离线、原生 SDK 未就绪分别验证提示；日志和脚本存储中不得出现认证值。
- 点击“刷新会话”，确认调用原生 token 刷新接口，刷新后业务请求使用 SDK 最新令牌；空结果和网络失败不能显示成功。
- 导出/保存期间阻止账号操作；折叠账号区清空未提交密码；刷新会话不提交密码。
- 页面闲置时本版本不会自动发送保活请求。Cookie 实際寿命和滚动续期需另行观察，不能由“刷新成功”推断。

## 3.9.8 自动登录 / 保活验收（替代上面的 3.9.7 保活行为）

- 默认不自动请求、不保存凭据。填写后勾选记住密码及自动保活，再保存，确认自动检查开始。
- 刷新页面后，邮箱和开关恢复，密码输入框不回填；同邮箱可留空手动登录，更换邮箱必须重新输入密码。
- 两个标签页开启后正常每 5 分钟只有一个刷新请求；离线/导出时暂缓。
- 服务端 /sessions/whoami 明确返回 401 后只尝试一次自动密码登录；网络错误、403/429/5xx 不得触发登录。
- 密码错误、验证码或登录中断后停止自动尝试；处理后保存设置可重新开启。
- 手动退出登录后所有页面停止保活；即使下次刷新尚未到期，也应先绑定退出事件。
- 取消保活、取消记住密码、清除账号密码，在请求进行中以及多标签页下均不应产生新的密码请求。
- 说明中清楚显示 localStorage 明文保存；脚本日志/导出内容不包含密码或 JWT。
- 浏览器关闭期间不保活；休眠恢复后做一次到期检查，不补发全部错过的请求。

## 3.12.6 跨工程批量导出验收

- 在资产列表勾选一个模型，确认复选框保持勾选且不会打开模型；再次点击后取消勾选。点击卡片其他区域仍能正常进入工程。
- 分别打开至少两个模型，先使用“记录当前导出点”或完成一次导出，为每个工程保存还原点；回到资产列表确认选择状态在刷新后保留。
- 选择截图和视频项目，创建跨工程批量任务并确认每个工程使用自己的记录视角、材质和 Canvas 尺寸。
- 第一个工程导出部分文件后刷新页面，选择原目标目录继续；已完成文件不重复输出，任务从保存的工程与文件索引继续。
- 运行期间点击取消，确认当前导出停止、已完成文件保留；再次点击“跨工程批量导出”应创建全新任务。
- 继续任务时拒绝或撤销目录权限，确认任务暂停并提示重新授权；重新选择目录后可续跑。
- 页面 hydration 期间观察尺寸变化：短暂变化应继续等待；布局稳定后仍与记录像素尺寸不一致时，应明确报错并停止导出。
- 在不支持线框的模型上运行含线框选项的跨工程任务，确认普通输出完成且任务不会因线框能力缺失而失败。
- 全部工程完成后确认状态回到“可创建新任务”，IndexedDB 不再保留该任务的目录句柄；目标目录中每个预期文件仅出现一次。
