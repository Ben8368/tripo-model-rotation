当前实现只隐藏可识别的独立 DOM 叠层；遇到未知结构保留画面，不擦除模型像素。

## 3.9.6 回归验收

使用测试副本或模拟响应验证运行门禁，不要为测试修改生产仓库状态。

- [ ] PNG 保存到慢速目录，在首次写入/提交期间刷新或关闭标签页，应出现离页确认；选择留在页面，保存正常完成，之后离页不再警告。

- [ ] 取消全部批量导出选项，刷新后仍为空；点击一键导出只提示选择项目，不开始导出。

## 3.9.7 账号登录与会话刷新

- 在工作区首页、带语言前缀首页和 Generate 子页面安装本地单文件包，确认面板可见，原有录制和快捷键仍正常。
- 用测试账户在“账号登录 / 刷新会话”提交密码，确认输入框立即清空、请求期间按钮禁用，原生页面同步登录成功状态。
- 查看 Network：登录 flow → 带 CSRF 的 password POST → 原生登录状态同步；不要保存含密码 / Cookie / JWT 的 HAR 到仓库。
- 正确/错误密码、离线、原生 SDK 未就绪分别验证提示；日志和脚本存储中不得出现认证值。
- 点击“刷新会话”，确认调用原生 token 刷新接口，刷新后业务请求使用 SDK 最新令牌；空结果和网络失败不能显示成功。
- 导出/保存期间阻止账号操作；折叠账号区清空未提交密码；刷新会话不提交密码。
- 页面闲置时本版本不会自动发送保活请求。Cookie 实際寿命和滚动续期需另行观察，不能由“刷新成功”推断。

当前状态：自动化测试通过；上述真实浏览器安装/账户端到端验收待执行。

## 3.9.8 自动登录 / 保活验收（替代上面的 3.9.7 保活行为）

- 默认不自动请求、不保存凭据。填写后勾选记住密码及自动保活，再保存，确认自动检查开始。
- 刷新页面后，邮箱和开关恢复，密码输入框不回填；同邮箱可留空手动登录，更换邮箱必须重新输入密码。
- 两个标签页开启后正常每 5 分钟只有一个刷新请求；离线/导出时暂缓。
- 服务端 /sessions/whoami 明确返回 401 后只尝试一次自动密码登录；网络错误、403/429/5xx 不得触发登录。
- 密码错误、验证码或登录中断后停止自动尝试；处理后保存设置可重新开启。
- 手动退出登录后所有页面停止保活；即使下次刷新尚未到期，也应先绑定退出事件。
- 取消保活、取消记住密码、清除账号密码，在请求进行中以及多标签页下均不应产生新的密码请求。
- 说明中清楚显示 localStorage 明文保存；脚本日志/导出内容不包含密码或 JWT。
- 浏览器关闭期间不保活；休眠恢复后做一次到期检查，不补发全部错过的请求。

以上真实账号验收尚未执行；自动化模拟测试不能证明实际跨日会话持续性。
